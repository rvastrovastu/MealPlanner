# Digital Dine MealPlanner

AI-powered meal planning, calorie tracking, grocery management, meal swaps, pantry recipes, and nutrition coaching for families.

## Features

- Weekly AI Meal Planning
- Family Nutrition Planning
- Pantry Recipe Generator
- Leftover Meal Generator
- Grocery Lists
- Calorie Tracking
- Meal Swaps
- Premium AI Coach

## Tech Stack

- SwiftUI
- Node.js
- Express
- OpenAI API
